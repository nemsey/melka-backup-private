# یادداشت‌های امنیتی ملکا — Trusted Proxy

> سند رسمی فاز ۱ (PN-008 BLOCK 3) · ۱۴۰۵/۰۷/۱۶
> شواهد تجربی: `download/pn008/trusted-proxy-test.json`

## معماری پروکسی

```
کلاینت (اینترنت)
   │  HTTPS
   ▼
Caddy پلتفرم (root · /app/Caddyfile — فقط-خواندنی برای کاربر z)
   │  X-Forwarded-For را با IP واقعی کلاینت بازنویسی می‌کند (اثبات تجربی)
   │  پورت 3000 کانتینر به بیرون اکسپوز نیست
   ▼
Next.js standalone (کاربر z · :3000)
```

## چه کسی می‌تواند مستقیم به ‎:3000 برسد؟

- **از اینترنت: هیچ‌کس.** پورت 3000 تنها درون کانتینر قابل دسترسی است؛ مسیر عمومی
  (preview/publish) ناگزیر از Caddy می‌گذرد.
- **درون کانتینر:** فرایندهای همان کانتینر (خود اپ، اسکریپت‌های نگهداری).
  هر کسی که به شل کانتینر دسترسی داشته باشد، از قبل دسترسی‌ای فراتر از این
  نگرانی دارد (دسترسی مستقیم به فایل DB و env).

## رفتار اثبات‌شده (آزمون ۱۴۰۵/۰۷/۱۶)

| آزمون | نتیجه |
|---|---|
| جعل `X-Forwarded-For: 5.6.7.8` از مسیر عمومی (پشت Caddy) | **رد شد** — IP ثبت‌شده: `21.0.0.1` (واقعی؛ Caddy بازنویسی کرد) |
| جعل `X-Forwarded-For: 1.2.3.4` مستقیم به ‎:3000 (درون کانتینر) | ثبت شد به‌عنوان `1.2.3.4` — تنها مسیر ممکن، درون کانتینر |
| `X-Real-IP` از Caddy | ناشناخته — پیکربندی Caddy برای کاربر z فقط-خواندنی و غیرقابل مشاهده (`/app/Caddyfile`: Permission denied) |

## تصمیم پیاده‌سازی (بند ۳.۳)

تمام روت‌ها IP را فقط از **تک‌نقطه تصمیم** `src/lib/auth/client-ip.ts` می‌خوانند:

1. **`X-Real-IP`** — اولویت مطلق (اگر پروکسی رسمی تنظیم کند؛ غیرقابل جعل از بیرون)
2. **نخستین مدخل `X-Forwarded-For`** — فقط با اعتبارسنجی شکل IP؛
   در تولید این مقدار عین IP بازنویسی‌شده توسط Caddy است (آزمون بالا)
3. هیچ‌کدام → `undefined` — نرخ‌سنج به سبدِ «کد پرسنلی» برمی‌گردد (محافظت بروت‌فورس حفظ می‌شود)

روت‌های مهاجرت‌یافته: `auth/master-login` · `auth/verify-otp` · `auth/request-otp` ·
`pm/connection` · `arm/connection` · `gap/connection`

## محدودیت‌های امنیتی شناخته‌شده

- **خواندن Caddyfile ممکن نیست** (مجوز) — اگر مالک پلتفرم مایل به تأیید قطعی
  `X-Real-IP` است، باید از پنل پلتفرم محتوای `/app/Caddyfile` را بررسی کند.
- **تاریخچهٔ گیت حاوی رازهای پیشین است** (کد مستر در دو کامیت + کلید تست) —
  پاک‌سازی کامل نیازمند بازنویسی تاریخچه است (تصمیم مالک؛ گزینه‌های الف/ب در گزارش PN-008).
- **IP در Direct درون‌کانتینری قابل جعل است** — پذیرفته‌شده و مستند؛ ریسک محدود به
  دارندگان شل کانتینر؛ نرخ‌سنج اصلی بر «کد پرسنلی» استوار است نه IP.
