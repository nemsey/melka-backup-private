# راهنمای مالک — بازیابی راز بوت از مخزن GitHub (نسخهٔ ۲ escrow)
> سند: ملکا-شورا-ن۰۱۲-۱۴۰۵ · BLOCK 3 · بند ۳.۲ · وضعیت: **طرح ارائه‌شده — مالک تصمیم می‌گیرد**

---

## وضعیت فعلی (بدون هیچ اقدام شما)

سامانه سه نسخهٔ موازی از راز بوت نگه می‌دارد که هر کدام سطح بقای متفاوتی دارند:

| # | مکان | سطح بقا | کی از بین می‌رود؟ |
|---|---|---|---|
| ۱ | `db/.runtime/boot-secrets.json` | بالا | فقط با پاک‌شدن کل دیتابیس |
| ۲ | `upload/.runtime/boot-secrets.json` | بالا | پاک‌شدن پوشهٔ upload |
| ۳ | `env.escrow.enc` + `env.escrow.meta.json` | **بالاترین** — در گیت و آینهٔ GitHub | فقط با نابودی کامل مخزن **و** آینه |

نسخهٔ سوم **رمزنگاری‌شده** است (AES-256-GCM با کلید مشتق از کد مستر شما با
scrypt سختِ حافظه). هر سه مکان در هر بوت به‌طور خودکار همگام و در صورت فقدان،
بازیابی می‌شوند — هیچ کاری لازم نیست.

## اگر مالک بخواهد: GitHub Secret (اختیاری)

برای حالتی که حتی به فایل رمزنگاری‌شدهٔ داخل مخزن هم اعتماد نمی‌کنید:

1. وارد GitHub شوید → مخزن `melka-backup-private` → **Settings → Secrets and variables → Actions**
2. دکمهٔ **New repository secret** → نام: `MELK_TOKEN_KEY_PLAINTEXT` → مقدار: کلید فعلی
   (کلید فعلی را با این دستور در سرور ببینید — فقط در محیط امن خودتان):
   ```bash
   cd /home/z/my-project && bun scripts/pn012/escrow-manager.ts status
   # اثر انگشت را می‌بینید؛ برای «خودِ کلید»:
   # python3 -c "import json; print(json.load(open('.env.local'))['MELK_TOKEN_KEY'])"
   ```
3. از این پس، در بدترین فاجعه (نابودی کامل سرور + رمزگشایی نشدن escrow رمزی)،
   می‌توانید کلید را از پنل GitHub کپی کنید و در `.env.local` بگذارید.

**بهای این گزینه:** کلید به‌صورت متن ساده در تنظیمات GitHub ذخیره می‌شود
(GitHub آن را رمز می‌کند، اما دسترسی مدیران GitHub نظری قابل‌رقابت است).
در حالی که `env.escrow.enc` فقط با کد مستر شما باز می‌شود.

**توصیهٔ شورا:** نسخهٔ سوم فعلی (رمزنگاری‌شده در مخزن) برای سناریوهای واقعیِ
پلتفرم کافی است؛ GitHub Secret را فقط اگر بخواهید یک لایهٔ چهارم دستی داشته باشید
فعال کنید.

## جدول تصمیم

| سناریو | چه اتفاقی می‌افتد؟ | نیاز به اقدام مالک؟ |
|---|---|---|
| ریست محیط پلتفرم (عادی‌ترین) | بوت بعدی خودش از escrow بازیابی می‌کند (~۱ ثانیه) | ❌ هیچ |
| پاک‌شدن دو مکان متنی | بازیابی از env.escrow.enc رمزی | ❌ هیچ |
| نابودی کامل کانتینر + مخزن | clone از آینه GitHub → escrow رمزی همراه کد هست | ❌ هیچ (تا وقتی کد مستر را بدانید) |
| گم‌شدن کد مستر | escrow رمزی باز نمی‌شود؛ کلید تازه تولید و سرویس بالا می‌آید | ✅ یک ورود مجدد ARM |
| نابودی کامل + بی‌اعتمادی به escrow رمزی | — | ✅ GitHub Secret (این سند) |
