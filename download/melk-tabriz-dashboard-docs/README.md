# داشبورد هوشمند چندعامله ملک تبریز

> لایه‌ی هوش تحلیلی و مدیریتی (Decision-Support) روی سامانه‌ی CRM دپارتمان ملک تبریز — `https://arm.melketabriz.ir`

**مالک و برنامه‌نویس و طراح: سید نعمت اله سیدی**

---

## این پروژه چیست؟ (و چه چیزی نیست)

این پروژه یک CRM املاک **نیست** و قصد جایگزینی سامانه‌ی موجود را **ندارد**. این اپلیکیشن یک **لایه‌ی هوشمند مکمل** است که:

- داده را از سامانه‌ی ملک تبریز **استخراج** می‌کند (نه ثبت مجدد)؛
- در قالب یک **داشبورد تک‌صفحه‌ای کاشی‌ای** ارائه می‌دهد؛
- هر کاشی یک **ایجنت هوشمند یادگیرنده‌ی** مستقل دارد که با بازخورد مدیر، اولویت بینش‌ها را در طول زمان بهبود می‌دهد؛
- روی **وب، موبایل اندروید و تبلت** (PWA + بسته‌بندی Capacitor) اجرا می‌شود؛
- **تک‌زبانه و تخصصی فارسی** است (RTL، ارقام فارسی، تقویم شمسی).

## فناوری

| لایه | انتخاب | دلیل |
|---|---|---|
| فریمورک | Next.js 16 (App Router) + TypeScript | یک پایه کد برای وب/اندروید/تبلت، TypeScript strict برای قابلیت اطمینان |
| UI | Tailwind CSS 4 + shadcn/ui + فونت وزیرمتن (محلی) | سرعت توسعه + بلوغ اکوسیستم + RTL فارسی |
| نمودار | Recharts | سازگاری کامل با React و سبک بودن |
| پایگاه داده | Prisma + SQLite | کش داده CRM و حافظه ایجنت‌ها بدون نیاز به سرویس خارجی |
| وضعیت | Zustand (persist) | ماشین وضعیت SPA و تنظیمات کاشی‌ها |
| PWA | manifest + Service Worker | نصب مستقیم روی اندروید؛ بسته‌بندی بومی با Capacitor |

## اجرا

```bash
bun install          # نصب وابستگی‌ها
bun run dev          # اجرای توسعه روی پورت 3000
bun run lint         # بررسی کیفیت کد
bun run test         # اجرای ۶۵ تست خودکار (با پایگاه تست)
bun run db:push      # ساخت/به‌روزرسانی شمای پایگاه داده
```

## ورود (سه مسیر)

1. **کارشناس**: کد پرسنلی (مثال: `410031320`) → کد پیامکی ۶ رقمی → ورود.
2. **مالک (کد مدیر)**: از لینک «ورود با کد مدیر» روی صفحه ورود — بدون پیامک، با دسترسی کامل (شامل Rollback سیاست ایجنت‌ها).
3. پیش‌فرض کد مدیر: `41372895` — تغییر با متغیر محیطی `MASTER_ACCESS_CODE` (توصیه‌ی امنیتی: پیش از استقرار تولید حتماً تغییر دهید).

> **اتصال همیشه واقعی است** — داشبورد مستقیماً به `arus-api.melketabriz.ir` (سامانه ARM) و `pm-api.melketabriz.ir` (سامانه پرسنلی) متصل می‌شود؛ قرارداد API با تحلیل باندل‌های رسمی دو سامانه کشف و با تست زنده تأیید شده است (جزئیات: `docs/API-INTEGRATION.md`). هیچ داده دمو وجود ندارد؛ همگام‌سازی خودکار پس‌زمینه به‌محض بازیابی سرورهای ملک تبریز فعال می‌شود.

## ساختار پروژه

```
src/
├── app/                        # مسیرها (فقط / دیده می‌شود؛ API Routes زیر /api)
│   ├── page.tsx                # پوسته SPA: auth → otp → home ⇄ tile
│   ├── layout.tsx              # RTL فارسی + تم + PWA متا
│   └── api/                    # BFF — تمام ارتباط با CRM از این‌جا
│       ├── auth/               # request-otp, verify-otp, master-login, session
│       ├── crm/                # transactions, experts, meta, interactions, lookup, visits, supply-demand
│       ├── agent/[tileId]/     # insight, feedback, stats, policy
│       ├── connection/         # status, reset
│       └── health/
├── core/                       # هسته مستقل از UI
│   ├── tiles/                  # قرارداد کاشی + رجیستری پلاگین
│   │   └── tiles/              # ماژول‌های کاشی (معاملات، کارشناسان، استخراج اطلاعات، بازدیدها، عرضه و تقاضا، تنظیمات)
│   └── agent/                  # ایجنت پایه + تحلیل‌گرها + ایجنت‌های تخصصی
├── lib/
│   ├── melk-api/               # لایه انتزاعی اتصال به ملک تبریز (تنها نقطه تغییر)
│   ├── auth/                   # crypto, rate-limiter, session, secure-storage, guard
│   ├── client/                 # api کلاینت + store
│   └── format.ts               # فارسی‌سازی اعداد/تاریخ/مبالغ
└── components/app/             # AuthScreen, OtpScreen, Home, TileShell, AgentPanel
```

مستندات کامل: `docs/ARCHITECTURE.md`، `docs/API-INTEGRATION.md`، `docs/BUILD-ANDROID.md`

## امنیت در یک نگاه

- توکن نشست **فقط هش‌شده (SHA-256)** در پایگاه داده ذخیره می‌شود.
- توکن سمت کلاینت **رمزنگاری‌شده (AES-GCM + کلید دستگاه در IndexedDB)** — هرگز متن ساده.
- محدودسازی نرخ: ۳ درخواست پیامک/۱۰ دقیقه؛ ۵ تلاش تأیید/۱۵ دقیقه + قفل خودکار.
- مقایسه‌ی کد مدیر **زمان-ثابت** (ضد Timing Attack).
- خروج خودکار کلاینت در انقضا/401؛ حسابرسی کامل رخدادها در `AuditLog`.
