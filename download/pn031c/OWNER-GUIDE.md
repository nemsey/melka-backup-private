# راهنمای سادهٔ مالک — نصب نهایی رله (PN-031-C)

**تاریخ:** ۱۴۰۵/۰۷/۲۲ · جلسهٔ فوق‌العاده ۰۴۰
**برای:** جناب سیدی · **موضوع:** نصب رلهٔ ملکا روی گوشی — نسخهٔ نهایی

---

## ۱) چه اتفاقی افتاده بود؟ (در سه جمله)

مشکل **از شما نبود**. کد نصب قبلی یک قانون سخت‌گیرانه داشت: **با اولین تلاش — حتی ناموفق — سوخته می‌شد**. به همین دلیل چهار بار خطا دیدید، هر بار به دلیلی متفاوت، اما همه از یک ریشه.

**آن قانون امروز برای همیشه برداشته شد.**

---

## ۲) چه چیزی عوض شد؟

| قبل | حالا |
|---|---|
| کد فقط ۱ بار قابل استفاده بود | کد **۳ بار** قابل استفاده است |
| تلاش ناموفق = کد می‌سوخت | تلاش ناموفق **هیچ ضرری ندارد** — همان کد دوباره کار می‌کند |
| پیام خطا کلی و گمراه‌کننده | پیام دقیق: «سوخته» یا «منقضی» یا «نامعتبر» |
| سرور گاهی به نسخهٔ قدیمی برمی‌گشت | نگهبان خودکار (head-guard) هر ۱۰ دقیقه سرور را به‌روز نگه می‌دارد |

---

## ۳) کار شما — فقط ۲ قدم (حدود ۲ دقیقه)

**قدم اول:** برنامهٔ Termux را روی گوشی Poco F3 باز کنید.

**قدم دوم:** دستور زیر را **کامل کپی** کنید، در Termux پیست کنید و Enter بزنید:

```
pkg install -y curl openssl jq && curl -fsSL "https://preview-chat-35e0018b-b9e9-411f-88d7-f1f774acfff0.space-z.ai/api/mobile-relay/bootstrap?code=a46e409e75f1dc8ddee25f02ad9217c2a851" -o ~/melka-relay.sh && chmod 600 ~/melka-relay.sh && bash ~/melka-relay.sh
```

*(این دستور در فایل `qr-install-command.png` هم به‌صورت QR هست — با دوربین گوشی می‌توانید کپی کنید.)*

همین. تمام.

---

## ۴) اگر خطا دیدید؟ — آرام باشید

- **همان دستور را دوباره پیست کنید.** این کد ۳ بار قابل استفاده است.
- کد فقط وقتی نهایی می‌شود که گوشی واقعاً به سرور وصل شده باشد — یعنی نصب موفق.
- کد تا ساعت اعتبار دارد (بخش تنظیمات ملکا ← رلهٔ موبایل ← زمان انقضا را نشان می‌دهد).
- اگر کد منقضی شد: از **تنظیمات ملکا ← بخش «رلهٔ موبایل» ← دکمهٔ «راه‌اندازی رله»** کد تازه بگیرید — دیگر لازم نیست منتظر GLM بمانید.

---

## ۵) بعد از نصب — تشخیص موفقیت

1. در Termux باید ببینید: **«رلهٔ ملکا فعال است»**
2. در تنظیمات ملکا ← رلهٔ موبایل:
   - وضعیت دستگاه: **«نصب کامل شده ✓»**
   - دکمهٔ **«تست تونل»** را بزنید → باید **سبز** شود («تونل زنده ✓»)
3. وقتی تست تونل سبز شد، به GLM خبر بدهید تا حالت آنلاین را فعال کند (گام آخر — ورود شما با کد پرسنلی و OTP).

---

## ۶) نکته‌های کوچک

- گوشی را شب‌ها روی شارژر بگذارید و در تنظیمات MIUI برای Termux «بدون محدودیت» باتری را انتخاب کنید.
- اسکریپت رله باید همیشه روشن بماند (Termux باز). اگر گوشی ری‌استارت شد، فقط Termux را دوباره باز کنید — اسکریپت خودش ادامه می‌دهد.
- اگر هر سؤالی بود: در تنظیمات ملکا، بخش رلهٔ موبایل، وضعیت لحظه‌ای دستگاه و کد را می‌بینید — عین صفحهٔ رادار.
