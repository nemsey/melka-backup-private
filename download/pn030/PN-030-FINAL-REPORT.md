## 🔬 بخش ۳ — گام سوم/چهارم: اجرای سفارش PN-030 (شورا-ن۰۳۵)

### ۳.۱ — مرحلهٔ ۱: پروژهٔ Cloudflare Worker «melka-proxy» ✅

مسیر رسمی و ماندگار در مخزن: `melka-proxy/` (+ رونوشس تحویل: `download/pn030/worker/`)

| قید مصوب شورا | اجرا | شاهد |
|---|---|---|
| whitelist فقط سه دامنهٔ API | `ALLOWED_HOSTS` + اجبار `https:` | تست B-1 |
| احراز HMAC | HMAC-SHA256 با **مقایسهٔ زمان-ثابت** | تست B-2 |
| ضد replay | پنجرهٔ ±۵ دقیقه | تست B-3 |
| صفر لاگ محتوا | صفر console/JSON.stringify — فقط شمارندهٔ درون‌حافظه | تست B-4 |
| هدرهای X-Melka-* هرگز به مقصد نمی‌روند | فهرست عبوری حداقلی (۴ هدر) | تست B-5 |
| پاسخ بدون کش | `redirect: "manual"` + `no-store` | تست B-6 |

قرارداد امضا (یکسان دو سر): `HMAC-SHA256(secret, "METHOD\npath?query\nsha256(body)\ntimestamp")`
